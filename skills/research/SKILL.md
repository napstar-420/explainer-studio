# Research

Write `projects/<slug>/research.md`:

- **Timeline**: dated events (year, what happened, who), oldest first.
- **Key facts**: founders/companies, places, products, prices, numbers, names of rivals.
- **Causes**: for a decline, outside pressures and own mistakes; for a success, the problem it
  solved, features, turning points.
- **Today**: current status with the most recent dated evidence (report, article, filing).
- **Visual hooks**: concrete objects, places, packaging, slogans that can become metaphors.
- **Sources**: numbered list (title, publisher, date, URL). Every fact above cites `[n]`.

Use web search; prefer primary sources and reputable press. Mark anything single-sourced or
estimated as such. If facts conflict, note both. Do not invent quotes or figures.
