# Market packs

A market pack is the audience layer: language, voice, sources, legal care, settings,
metaphors and topics for one country. Everything else (style, components, pipeline) is shared.

- `uk/`: United Kingdom, British audience (default).
- `pk/`: Pakistan (the market of the reference videos).

The workspace default is `market` in `studio.json`; a video can override it with `market:` in
its `brief.md`. To add a market, copy `uk/` and rewrite both files.
