# Library

Reusable, licensed files shared by every video. Copy what a video uses into `public/<slug>/` (or
reference `public/library/...` after copying this folder into `public/`).

- `sfx/`: short effects named by what they are: `whoosh.mp3`, `pop.mp3`, `thud.mp3`, `coin.mp3`,
  `paper-fold.mp3`, `switch.mp3`, `shutter.mp3`, `ding.mp3`.
- `music/`: calm, loopable beds (documentary, light piano/pluck), 60–120 s.
- `fonts/`: title fonts (`.ttf`/`.woff2`) if you want something other than the system sans.

Only add files you have the right to use; note the source and licence in `CREDITS.md`.
